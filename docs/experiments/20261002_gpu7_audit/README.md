## 错误定位与诊断结果

旧故障发生在`store_laptop_and_headphones_random/seed0`动作398→399附近：先是env3笔记本坐标约`(1.14e11, 1.23e12, -1.24e11)`，再有多环境物体Invalid PhysX transform，随后关闭/重建中报告CUDA700。旧截断日志曾误导为初始化故障，完整日志纠正了该判断。首次坏物理状态早于相机关闭，不能把相机清理当本次唯一根因。

独立N4诊断完成4回合、800动作/8000物理tick、12视频，任务成功0/4；动作有限，最大绝对值2.438。四个笔记本根速度最大0.417–0.710m/s，两link质量0.250259/0.244225kg，惯量正定且条件数约3.1–3.2；本次未复现发散，没有依据新增求解器、碰撞器或质量补丁。

相同seed/layout不等于历史动作回放：当前Pi05为JAX分支，推理每次推进RNG，reset仅清观测。历史服务器先跑其他任务，本次先跑笔记本，推理调用历史不同；取证读取本身也增加同步。因此未复现不能证明某项改动治好了700。
